# AI 自动因子研究控制框架

开发一个控制 AI 如何开展因子研究的框架。研究者定义研究目标、可用资源和约束。框架根据实验状态和证据，决定 AI 下一步应该做什么、哪些候选值得继续、何时改变搜索方向，以及何时停止。交付的是这套控制能力，不是某个因子、因子库或一份回测结果。

## 框架负责什么

- **组织研究。** 把提出假设、生成候选、执行实验、评价证据和决定下一步串成可重复运行的流程。根据结果继续搜索、修订假设、扩大探索或终止，而不是每轮重复生成公式。
- **约束实验。** AI 可以提出假设和行动，但不能自行宣布假设成立。评价依据可复算的实验结果。冻结的评价协议、数据使用范围、样本外边界和资源预算不能由 AI 根据结果改写。
- **积累证据。** 记录候选的演化过程、试过的方向、失败原因和适用条件。后续研究可以复用有依据的经验。最终独立验证的结果不进入搜索反馈。
- **管理运行。** 能说明为何做出某个决定、已花多少预算、哪些尝试失败，并在中断后从有证据的状态继续。

框架不绑定市场、数据类别、时间频率、字段、因子表示、模型或搜索算法。每项研究按目标选择资源和方法。评价的重点是框架能否在不同研究任务中可靠控制过程，而不是示例跑通或找到高收益因子。
