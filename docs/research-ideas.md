# 自动因子研究的近期理念

以下为原始调研中的代表方向，包含 2026 年论文和预印本。它们提供可比较的研究思想，不是排行榜，也不构成实现清单。

| 研究方向 | 代表工作 | 关键理念与边界 |
|---|---|---|
| 先验证假设，再解释成绩 | [FaVOR](https://arxiv.org/html/2608.30192v1) | 把经济假设拆成可观察的条件并分别检验。预测得好不代表因子实现了它声称的机制；条件一致也不是因果识别。 |
| 把失败变成可检索经验 | [FactorMiner](https://arxiv.org/html/2602.14670v1) | 从已有经历选方向，将冗余、拒绝和更优替换的原因记下来。经验应带出处和适用条件，不能代替新实验。 |
| 分开搜索逻辑和参数 | [FactorEngine](https://arxiv.org/html/2603.16365v3)、[CogAlpha](https://aclanthology.org/2026.acl-long.538.pdf) | 修改机制、优化参数和检查实现是不同的行动。受约束的程序表示能拓宽搜索空间，但不会自动带来可执行性、安全性或正确性。 |
| 搜索高质量且不同的解 | [GoAnt](https://arxiv.org/html/2609.08719v1)、[AlphaSAGE](https://arxiv.org/html/2509.25055v1) | 分别探索不同类型的候选，避免全部挤到相似方向。结构不同不等于信号或收益独立；发现效率也不等于净收益。 |
| 研究策略本身可以改进 | [AlphaAgentEvo](https://proceedings.iclr.cc/paper_files/paper/2026/file/741aab8b41a2987867acc9939ad50383-Paper-Conference.pdf)、[AlphaRJM](https://arxiv.org/html/2609.08581v1) | 可以学习怎样探索，而不只是生成更复杂的候选。训练策略、从记录中检索经验和估计搜索价值是三件不同的事，不应把它们都称为模型自我训练。 |

这些研究共同提出一个控制问题：有限预算下，怎样选择下一项最有价值的实验，并保留足够的证据来推翻自己的判断。控制器需要分清探索反馈、可重复的验证证据和最终独立验证。反复查看最终验证结果来调整搜索，即使只看一个评分，也会破坏它的独立性。
